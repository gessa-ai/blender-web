# M8 deferral-registry honesty contract

This device-free contract binds every launch-visible forced-off feature family to a complete,
named `ledger/deferred.json` row and keeps the six hardware deferrals scoped to this WSL2 host.
It rejects the obsolete Windows-reboot revisit path without weakening any adapter or receipt gate.

Run through the repository output wrapper:

```sh
harness/buildwrap.sh .host-tools/bin/python3.13 sandbox/m8-deferral-registry/verify.py
```
