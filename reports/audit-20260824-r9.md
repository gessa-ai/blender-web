The exact immutable range is `c36e225^..44186b4`: 25 commits from `c36e225` through

The headline is a fidelity regression, not receipt inflation. Eight default windowed feature

type-specific state. Opening and saving an affected `.blend` can therefore destroy data.

was used as a receipt/profile/split product, and the exact s7 blocker remains unchanged.

## Findings

### CRITICAL-1 - size-only feature deferrals violate the fidelity-first decision

Patches 0248-0255 add eight options and force every one OFF in the default windowed profile
(`patches/blender_web.cmake:59-95`). The resulting browser omits sculpt/paint operators and
keymaps, Grease Pencil editing, compositor execution nodes, the VSE, Spreadsheet, Clip and NLA
editors, and physics editing. `ledger/deferred.json` registers all eight omissions with the
15 MB payload budget as their blocker.

That is the exact tradeoff prohibited by D-10. `notes/decisions.md:156-173` says to choose
native fidelity when payload conflicts with parity, to handle wire pressure with staged/lazy
loading, and to accept deferrals only for hard external blockers. A size target is not an
external platform impossibility. The later Mask experiment correctly applies D-10 and rejects
a 1,452-byte win, but it leaves the previous eight contradictory decisions in force.

The cuts also do not close the budget. Together they remove 1,254,866 Brotli-q11 bytes, taking
the Wasm from 24,725,899 to 23,471,033 bytes. The final Wasm alone remains 8,471,033 bytes over
the complete 15 MB interactive budget before stage-0 data, and required M8 remains 0/1 red.
The project traded fidelity without advancing a harness boundary.

The corrective unit must restore all eight registration roots and the faithful windowed
defaults, retire the size-only deferrals while retaining their measurements as rejected
history, and regenerate the canonical postimage. A future profile-driven split may stage this
code only after an accepted hardware profile exists. If that profile cannot meet the budget,
the truthful result is a named M8 performance deferral, not a narrower Blender product.

### CRITICAL-2 - omitted compositor registration destroys node identity and storage on load

Patch 0250 keeps `register_node_tree_type_cmp()` but skips `register_compositor_nodes()`
(`patches/0250-web-windowed-compositor-registration-cut.patch:33-44`). Its verifier treats the
tree-type registration as sufficient for data/RNA loading
(`sandbox/m8-compositor-cut/verify.py:76-112`), but Blender's file loader requires each concrete
node type too.

The pinned source builds the known built-in set from the registered node types
(`upstream/source/blender/blenkernel/intern/node.cc:5536-5566`). After file read,
`node_tree_update_all_new()` replaces every unknown built-in node with `NodeTypeUndefined`.
The upstream comment is explicit that this replacement changes the idname and discards storage
and other type-specific data (`node.cc:5569-5595`). A storage-bearing compositor node loaded by
the windowed build is therefore not merely unavailable for execution: its identity and storage
are destructively downgraded before a later save.

This violates the launch-tier `.blend` open/save contract and the note's claim that generic
file loading remains intact. Restore concrete compositor registration. The regression should
author a compositor tree containing storage-bearing nodes in the native oracle, load/save it
under the browser profile without GPU work, reload both outputs, and require exact node idname,
socket, link, and storage parity.

### CRITICAL-3 - omitted editor spaces are converted to SPACE_EMPTY and lose regions

Patches 0251-0254 skip the VSE, Spreadsheet, Clip, and NLA `SpaceType` registration roots.
The focused verifiers prove only source/patch structure and generated build rules. Their
`run_roundtrip()` name refers to reversing and reapplying a patch, not to a `.blend` file
round-trip.

Blender's loader does not preserve an unregistered editor opaquely. During direct link it tests
`BKE_spacetype_exists()` and rewrites every missing `SpaceLink.spacetype` to `SPACE_EMPTY`
(`upstream/source/blender/blenkernel/intern/screen.cc:1583-1600`). After liblink it frees all
regions for a missing type (`screen.cc:1657-1673`). UI initialization then replaces an unknown
active area with a View3D fallback (`upstream/source/blender/editors/screen/area.cc:2204-2244`).
On save, type-specific `blend_write` is unavailable (`screen.cc:1374-1383`).

Thus an affected workspace opens with altered layout/state and a subsequent save cannot
round-trip the discarded editor data. Restore the four space registrations. Add native-authored
fixtures with each editor active and inactive in `spacedata`, then require load/save/reload
state parity before any future lazy-loading boundary is accepted.

### MAJOR-1 - the callback census accepts an unmanifested raw-owner alias callback

Commit `c36e225` improves the old string count, but the new analyzer enumerates only calls to
`->deliver` and `fallback_device_loss_notify` (`sandbox/audit-r8/callback_census.py:566-585`).
Its global lambda scan rejects `this`, implicit captures, and four known gate/state names
(`callback_census.py:587-613`); it does not enumerate every `AllowSpontaneous` callback
registration or trace a differently named owner alias.

A mutation adding a new `PopErrorScope(AllowSpontaneous, [owner_alias] { ... })` callback after
`auto *owner_alias = this` is accepted as the same eight-role census. The exact in-memory probe
prints `AUDIT_R9_CALLBACK_ALIAS_GAP_REPRODUCED roles=8`
(`ledger/buildlogs/20260824T084359-3932717.log`). The committed "extra callback" self-test only
duplicates the already manifested adapter call, so it fails through duplicate-role counting and
does not exercise this gap.

No current ninth owner-affine callback was found, and the real native/wasm32/ASan behavior suite
remains green. This is an evidence defect that can certify a future UAF. Enumerate all
`CallbackMode::AllowSpontaneous` registrations by structural callsite and require every
owner-affine completion to enter the lifetime gate; retain a raw-owner-alias mutation that must
be rejected.

### MAJOR-2 - five size-cut round-trip verifiers are not composable

The final stacked postimage no longer passes the focused `--roundtrip` modes for Grease Pencil,
VSE, Spreadsheet, Clip, or NLA. Each verifier copies the final two-file postimage and attempts to
reverse only its own patch, but later adjacent patches changed the same hunks. The five reverse
checks fail immediately (`ledger/buildlogs/20260824T084359-3932714.log`). Compositor and the final
Physics patch still pass; Sculpt/Paint exposes no verifier-owned round-trip mode.

Canonical squashed replay remains green, so this is not a source-reconstruction failure. It does
show that the per-cut evidence advertised in the notes cannot be rerun as a regression suite and
that no aggregate control accompanied the serial stack. The fidelity rollback should remove
these shipping-cut verifiers. If historical diagnostics are retained, reconstruct the exact
patch prefix in a pristine pin or reverse the complete suffix instead of applying a single patch
to a later postimage.

### MINOR-1 - the inheritance correction leaves a second contradictory startup comment

Commit `0ca3bc3` corrects the file-level comment to say the shipping path imports a pre-main
device/surface and `initAsync()` is standalone-only
(`platform_web/ghost/GHOST_ContextWGPUWeb.hh:20-31`). The class comment immediately below still says a "one-time startup await" runs
`initAsync()` and gates WM main-loop start (`GHOST_ContextWGPUWeb.hh:46-54`). Those descriptions
cannot both be true.

The source-compliance check reads only the header prefix through `#pragma once` and rejects only
the distinct phrase "one-time top-level await" (`sandbox/audit-r8/run.sh:23-38`), so it passes
while the stale class comment survives. Consolidate the lifecycle text and bind the full class
comment or remove the duplicate paragraph.

### MINOR-2 - the zero-harness-progress stuck protocol was skipped

From Sculpt/Paint through Physics, every accepted cut left required M8 red; the Script and Mask

zero-gate iteration, despite GOAL.md's explicit stuck protocol. The lane continued serial marginal
cuts until the Mask note finally concluded that they were spent.

This audit adds the required diagnosis in `notes/stuck-2026-08-24.md`. The recovery is to stop
