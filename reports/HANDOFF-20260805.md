**The gate is one Dawn validation error away from the project's first rendered frame.**
Sequence of what happened, newest-first-relevant:

1. The full WebGPU backend skeleton, context, buffers, shaders (real WGSL compile via
   shaderc→Tint), textures, framebuffer, pipeline, batch draw, and immediate-mode paths
   are ALL implemented and compile-green in `upstream/source/blender/gpu/webgpu/`

   0034(push-constants), 0035(immediate), 0036–0041.
2. Two structural crashes were root-caused and fixed this session:
   - Shader `finalize()` returned NULL modules because it ran on an async warm-up
     worker thread where the thread-local active-context was null. Fixed by
     publishing the Dawn device/queue as backend-side statics (patch 0036).
   - `GPU_offscreen_create` SIGSEGV'd because `WGPUContext` never created default
     `back_left`/`front_left` framebuffers (`GPU_framebuffer_restore()` null-derefed).
     Fixed with the 3-line `vk_context.cc`-mirroring ctor addition (patch 0039).
3. A worker's **polyline-shader diagnosis was investigated, found to be a mis-grep,
   and explicitly RETRACTED** after independent re-verification (`GPU_SHADER_3D_UNIFORM_COLOR`
   is NOT polyline — only the 4 `GPU_SHADER_3D_POLYLINE_*` shaders are). Trust this
   retraction; it was self-caught and re-verified, exactly per the "verify, don't trust"
   discipline. The polyline/SSBO draw path is **deprioritized, off the critical path**.
4. **Current true state:** `blend_none`'s draw call executes with a valid pipeline and
   a correctly-formed push-constant bind group (verified against the auto-inferred
   bind-group layout), but Dawn drops it with a validation error. The error MESSAGE was
   invisible (Dawn's `PopErrorScope`/`WaitAnyOnly` returns an empty string on this
   build, and the callback can only be registered at device-creation time — not
   after). **Patch 0040 (just landed, verified firing) adds a device
   `SetUncapturedErrorCallback` that logs the full message.** Its first real capture
   already exposed one genuine bug (a storage buffer missing `CopyDst` usage).

**The single next action:** rebuild with 0040 in the tree, run `blend_none`, read the
`[WebGPU] uncaptured device error (type N): <message>` line from stderr (use `grep -a`

## Operating model (how this session ran the fleet — replicate it)

- **Orchestrator role only.** Never grind compile errors personally — dispatch a
  worker, verify its claims independently (build artifacts on disk, commit diffs,
  actual test output), then integrate.
- **Shared-tree protocol** (multiple workers touch `build-wasm-gpu`/`build-native-gpu`
  + `upstream/source/blender/gpu/webgpu/` concurrently): strict file-ownership per
  lane, ALL ninja invocations through `scripts/ninja-locked.sh` (serializes builds;
  the wave's parallelism is in error-fixing, not compiling), never restore/stash
  `upstream/` mid-push, capture fixes as numbered patches per-lane range.
- **Every worker prompt** carried: current verified state, exact file ownership,
  the hard rules (buildwrap only, no raw logs, upstream stays applied, 3-attempts-
  then-characterize-and-stop, `__EMSCRIPTEN__`-guard all fixes for native
  byte-identity), and "a precisely characterized failure beats an optimistic summary."
- **Recovery pattern for interruptions** (this session hit ~8 of them: quota kills,
  host-process restarts, one spend-limit — this document exists because of the last
  one): pulse-check disk state first (never assume; `git log`, buildlogs, `git status`),
  snapshot `git -C upstream diff` as insurance before anything, then resume each
  worker with an explicit message describing its exact last on-disk position. Zero
  work was lost across any interruption this session — the discipline works.
- **golden judges / first-pixels scoring infrastructure is staged** (referenced in
  progress.txt as "M4 goldens accepted — first-pixels judges staged" — locate via
  `git log --oneline | grep -i golden` if not obvious) — use it the moment real
  rendered frames exist to score them against tolerances, per GOAL.md's tier-(c)
  parity definition.
