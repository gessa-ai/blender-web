## High finding

### 1. The complete-wire receipt ignores unlisted same-origin requests (`b1474cd`)

`sandbox/m8-launch-gate/measure_current.mjs:318-320` constructs `transportUrls` from the fixed
`BOOT_CRITICAL_URLS` list plus the finalizer-owned Wasm inventory. The context request listener at
lines 339-349 records timing only for those paths; an unlisted same-origin request is neither
recorded as critical nor rejected as external. Lines 394-410 then derive `criticalPaths` from that
same fixed list plus observed critical Wasm. The consumer's
`test_technical_receipt_contracts.py:62-93` asserts the identical hard-coded list, so it cannot
detect a missing request class.

Consequently a Stage-1 manifest/data request, standalone worker, scene, or future same-origin
response dispatched before semantic interaction can escape both the 15,000,000-byte total and the
phase proof while the receipt remains structurally valid. Exact bundle-tree identity proves which
files exist; it does not prove when the browser requested them. This contradicts the stated “all
responses fetched before semantic interaction” contract in
`notes/m8-complete-critical-wire-20260826.md:14-19`.

Required repair: record every same-origin request from navigation through semantic interaction,
map every observed response to an exact bundle artifact, and derive the critical byte set from
that observation. Unknown, duplicate, or unmappable requests must fail closed. Add an adversarial
case that injects an unlisted early same-origin request and requires it to be counted or rejected.

## Medium findings

### 2. A transient Stage-1 failure is permanent until page reload (`ba0ceee`)

`sandbox/m8-staged-deploy/stage1-loader.js:117-131` sets `started = true` before checking the
module or completing either fetch, then returns on every failure without clearing the latch.
Every later `window.__bwStage1Load()` returns the same error state without issuing another request.
The contract at `verify_public_query_hardening.mjs:278-294` accepts HTTP, oversize, and underflow
errors but never retries in the same page. HEAD now defers 2,963 files / 152,362,255 bytes
(`notes/m8-stage0-false-color-lut-20260826.md:14-24`), so one transient transfer error disables a
large part of Blender for the rest of the session and prevents Stage-1 precache completion.

Required repair: make concurrent calls share one in-flight promise, clear retry state after a
failed attempt, reset accounting safely, and expose a bounded automatic or explicit retry. Prove
503-then-success and interrupted-stream-then-success in one page, including honest progress UI.

### 3. The non-streaming fallback can report success for truncated data (`ba0ceee`)

`stage1-loader.js:94-100` accepts any `arrayBuffer()` length and replaces `bytesTotal` with the
received length instead of comparing it to `man.total_bytes`. Later extraction uses clamped
`subarray()` views while lines 142-157 advance accounting by the declared manifest spans. A short
buffer can therefore write empty/truncated files and finish as `done` / “Assets ready.” The
fallback positive at `verify_public_query_hardening.mjs:273-276` uses exact bytes; corrupt-size
negatives at lines 284-294 exercise only the streaming-reader branch.

Required repair: enforce exact manifest length in both fetch branches before any write, validate
manifest spans against the received buffer, and add short/long fallback mutation cases that cannot
reach `done`.

### 4. Stage-1 retains the complete 152 MB payload while copying it into WasmFS

`stage1-loader.js:101` preallocates the complete response, and lines 142-155 retain it while
`FS.writeFile` copies every file into the live filesystem. The current payload is 152,362,255
bytes, not the “37 MiB” still claimed by the release comment at line 155. The present design delays
all deferred availability until the full response arrives and risks roughly a payload-sized peak
duplication without a launch soak/peak-memory receipt.

Required repair: measure peak browser/Wasm memory on the current payload, remove the stale size
claim, and install bounded chunks/files without retaining the entire payload twice, or document
and enforce a measured safe ceiling in the M8 soak gate.
