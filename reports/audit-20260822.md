The exact range is `908449b^..fc63056`, exactly 25 commits from `908449b`

## Major - native BC uploads were unreachable

Patch 0170 made compressed texture allocation require
`TextureCompressionBC`, but native `GHOST_ContextWGPU` did not request that
feature. Pinned Dawn enables the descriptor's requested features; therefore a
capable native adapter still produced a device on which every BC allocation
failed. The pre-fix cross-source check reports the exact missing feature in
`ledger/buildlogs/20260822T081730-1205090.log`.

Patch 0172 now adapter-guards and requests `TextureCompressionBC`. The real
staged GHOST postimage compiles and its selector exhausts all 1,024 masks across
ten optional features in `20260822T083944-1223152`. The extractor and transcript
mutation controls pass in `20260822T083944-1223057` and `1223082`. A final
cross-source comparison finds no device-consumed feature omitted from native
device creation in `20260822T084103-1226742`.

This repairs source-level native reachability only. The live control still
rejects llvmpipe before context creation in `20260822T083948-1223314`; no
hardware result or receipt was bound.

## Major - unsupported optional formats returned false-success wrappers

Patch 0165 correctly made attachment usage feature-aware, but it did not reject
feature-gated format creation. At the pinned Dawn revision,
R/RG/RGBA16Unorm requires `Unorm16TextureFormats` or `TextureFormatsTier1`, and
D32/S8 requires `Depth32FloatStencil8`. Dawn returns a non-null error texture
after descriptor validation fails, so the backend's later null-handle check
could accept an unusable wrapper. The unchanged source fails the exact creation
guard check in `20260822T082636-1213278`.

Patch 0173 adds one pure `format_creation_supported` predicate shared with the
attachment feature set and calls it before `CreateTexture`. It preserves BC's
feature/type rejection, SNORM16 Uint emulation, and Float32/RG11 capability-only
gates. The native and wasm32 contract exhausts 448 combinations with 368
accepted and 80 rejected cases, plus an unknown-gate rejection, byte-identically
in `20260822T083951-1223440`. The driver also requires the immediate fail-closed
return to precede the sole production `CreateTexture` call.
