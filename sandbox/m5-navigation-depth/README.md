# M5 ordinary-navigation depth continuation contract

This device-free contract binds ordinary mouse navigation to the shared owned progressive-depth
request. It checks immediate native completion, a browser-pending initialization barrier, exact
hit and stock fallback pivots, latest motion/release replay, and fail-closed drift, Escape,
readback-failure, and timeout paths. The source verifier also compiles the patched translation unit
with the exact locked native and Wasm product commands.

This is source and state-machine evidence, not a browser, hardware-adapter, profile, split-product,
or live M5 receipt. Direct dolly, painting, zoom-border, and NDOF depth consumers plus the depth
cache and window-capture families remain.
