# M8 public disclaimer source contract

This browser-free check binds the root README and visible launch shell to the standing
non-affiliation and trademark wording in `LAUNCH.md`. It also keeps the local-runtime proof,
desktop limitation, pending source-link boundary, same-origin legal link, and diagnostics-first
script order exact.

Run it through the repository output wrapper:

```sh
harness/buildwrap.sh .host-tools/bin/python3.13 sandbox/m8-public-disclaimer/verify.py
```

The verifier exercises the live sources and eight in-memory mutations. It produces no browser,
adapter, deployment, profile, or launch receipt.
